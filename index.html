REDISCOVER THE ORIGINAL

Back to the classic QL.

A cursor waiting for your ideas. A line of SuperBASIC that makes something happen. A game to discover. Here, the QL is once again a computer that invites you to experiment — at your own pace, one command at a time.

To open the SuperBASIC guide, we will end the chat and restart the QL. You will use the emulator as the original machine, without Gemini or another AI model.

Restarting clears the program in memory, including the chat terminal. Mounted cartridges are kept. At the QL startup screen, press F1 to enter SuperBASIC.

When you want to chat again, open QL Chat. Your Gemini settings are kept.

 YOUR QL · YOUR WAY

A classic.
New conversations.

Explore SuperBASIC, load software and use the QL freely. As an optional extra, you can chat through the QL using Gemini with your own API key.

Your key in three steps

  1. Open Google AI Studio in a new window ↗ and sign in with your Google account.
  2. Choose Create API key and select or create a project. Check that the plan is Free, with billing disabled.
  3. Copy the API key (not the project ID) and paste it below. Each user must create their own; there is no shared key.

The emulator stays open in this window. After copying the key, come back here to paste and save it.

Please note: the project ID is not the API key. A value such as gen-lang-client-… only identifies the project. In Google AI Studio, copy the API keyvalue, not the project name, number or ID.

This confirmation allows chat to be enabled; it does not check or change Google billing. Without confirmation, Gemini stays disabled.

The key and confirmation are saved in the .env file in the project root, alongside package.json. This file is excluded by .gitignore and blocked by the web server. Do not share it or include it in a project ZIP. The key is not stored in the browser; the local server uses it to contact Google when you choose Gemini, sending your messages and recent context. About the connection and privacy

The local demo tests the terminal without AI or sending messages to third parties.

With Gemini, you are chatting with an AI: your messages and a short history are sent to Google. The key stays on the local server. Check important facts against other sources.

Use a Free project with billing disabled. When the quota is exhausted, chat stops, with no automatic retries or paid fallback. See the terms of use in credits and privacy.
